## 🚀 About StarManager

**StarManager** is a modern dual-pane file manager designed to make managing files faster, easier and more intuitive.

Developed using Rust and the Slint UI framework, StarManager combines a clean interface with powerful file-management features.

---

## ✨ Features

| Feature | Description |
|---|---|
| 🗂️ Dual-Pane Interface | Browse and manage two directories side by side |
| 💾 Drive Navigation | Quick access to local, removable and network drives |
| 📁 File Operations | Copy, move, rename and delete files |
| 🖱️ Drag & Drop | Move and copy files with drag-and-drop support |
| ☑️ Multi-Selection | Select multiple files and folders |
| 👁️ File Preview | Preview supported files inside the application |
| 🎨 Customisable Interface | Configure file columns, layout and appearance |
| ⚙️ Persistent Settings | Automatically remember your layout preferences |
| 🦀 Rust Powered | Built with performance and reliability in mind |
